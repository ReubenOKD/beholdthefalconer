First time on this device?

Paste your GitHub access key once. It stays only in this browser (never on the site). To make one: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Choose "Only select repositories" → beholdthefalconer, then under Permissions set Contents to Read and write. Pick the longest expiry offered.
